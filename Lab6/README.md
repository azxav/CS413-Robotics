## Program

Blocks only. Left wheel `M4`/`E4`, right wheel `M3`/`E3`.

```
Initial Node → Clear Encoder (E3, E4) → Remove File → Function "init" (r, B, segments, gains)
 → Loop (seg < N)
     iteration → Function "step" (odometry + segment controller)
               → Motors Forward M4 = uL → Motors Forward M3 = uR → Write To File → Timer 20 ms → back to Loop
     exit      → Stop Motors → Final Node
```

Segment controller (same method as a straight/turn/pause list):
- **straight**: drive the distance, hold the segment heading (`w = KH·e`), slow down near the end.
- **turn**: turn on the spot to an absolute heading; done when `|e| < 0.02 rad`.
- **pause**: stand still for the time.
- Each straight/turn gives up after 8 s, so the program always ends.

Segments, start at the top-left corner of the "3", robot facing +x (heading 0°, right turn = −):

```
3: straight 0.30 | turn -90 | straight 0.30 | turn -180 | straight 0.25 | turn 0 | straight 0.25
   | turn -90 | straight 0.30 | turn -180 | straight 0.30 | pause 1.5 s
0: turn 0 | straight 0.75 | turn 90 | straight 0.60 | turn 180 | straight 0.30 | turn 270 | straight 0.60
```

Simulator: 55 s, odometry end (0.446, −0.600) m, planned end (0.45, −0.60) m.

The robot needs about 1.0 m × 0.8 m of floor (0.8 m along the start heading, 0.6 m to its right).

## Real run — steps

1. Measure wheel radius `r` and track width `B` (centre to centre of the wheels). If different, change them in the first *Function* block of `trajectory_real.qrs`.
2. Check ports: left motor `M4`, encoder `E4`; right motor `M3`, encoder `E3`. Spin each wheel forward by hand: both encoders must increase. If one decreases, swap that port or put `-encoderN`.
3. Mark the start point and heading on the floor with tape.
4. Upload and run `trajectory_real.qrs`. Do not touch the robot until it stops.
5. Measure the real end point with a tape (x along the start heading, y to the left; right = negative). Put it in `MEASURED_END` in the notebook.
6. Download `/home/root/trik/scripts/odm_240030.txt` from the robot to this folder (WinSCP or TRIK Studio file tool). Rename it to `odometry_data_real.txt` (deliverable name). The notebook also reads `odm_240030.txt` if not renamed.
7. Run the notebook. Write the 3–6 sentences in section 6.
